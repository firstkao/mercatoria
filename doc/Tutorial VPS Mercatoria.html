1. Ringkasan Sprint 0 & Arsitektur VPS Hostinger KVM 1 + CloudPanel + PHP 8.5 + Laravel 13.x

Kenapa Kombinasi VPS Hostinger KVM 1 + CloudPanel v2 + PHP 8.5 + Laravel 13.x Sangat Optimal untuk Mercatoria?
  • KVM 1 (1 vCPU · 4 GB RAM · 50 GB NVMe) + CloudPanel (~120 MB RAM): Sangat hemat memori. Dibandingkan panel lain yang memakan >1 GB RAM, CloudPanel menyisakan >3,5 GB RAM murni untuk PHP 8.5-FPM, MySQL 8.0, dan Redis 7.
  • Performa PHP 8.5 + JIT & Native Functions: PHP 8.5 membawa peningkatan performa JIT compiler, penghematan memori OPcache, serta fungsi native seperti array_first() dan array_last() yang digunakan langsung oleh Laravel 13 tanpa overhead polyfill.
  • Arsitektur Ramping Laravel 13.x: Seluruh konfigurasi routing, middleware, dan exception dipusatkan di bootstrap/app.php, penjadwalan 13 cron job langsung ditulis di routes/console.php, dan Event Listener (seperti SuppressCustomerEmailWhenPaused) otomatis terdeteksi (auto-discovered) tanpa perlu file Kernel.php atau EventServiceProvider.php warisan versi lama.
  • Zero Permission Error (Isolated Site User mercatoria): Di CloudPanel, PHP 8.5-FPM pool dan user SSH berjalan di bawah user Linux yang sama (mercatoria), sehingga tidak pernah terjadi konflik www-data vs root pada storage/ maupun bootstrap/cache/.

Langkah 4.3 — Buat File app/Helpers/helpers.php (Task 3.2b)

<?php

use App\Models\Setting;
use Illuminate\Support\Facades\Cache;

if (! function_exists('setting')) {
    /**
     * Ambil nilai setting dari database (dengan cache Redis 10 menit) atau fallback ke default.
     */
    function setting(string $key, mixed $default = null): mixed
    {
        try {
            $settings = Cache::remember('app_settings_all', 600, function (): array {
                return Setting::pluck('value', 'key')->toArray();
            });
            return $settings[$key] ?? $default;
        } catch (\Throwable) {
            return $default;
        }
    }
}

if (! function_exists('format_rp')) {
    /**
     * Format angka ke Rupiah bersih (contoh: Rp255.000)
     */
    function format_rp(float|int $amount): string
    {
        return 'Rp' . number_format((float) $amount, 0, ',', '.');
    }
}

10.2 Panduan Troubleshooting 6 Masalah Umum di VPS Hostinger KVM 1 + CloudPanel + PHP 8.5 + Laravel 13

#Gejala / Masalah yang MunculPenyebab & Solusi Pasti di CloudPanel (PHP 8.5 + Laravel 13)
1Perintah composer error: "Your Composer dependencies require a PHP version >= 8.5.0" padahal sudah pilih PHP 8.5 di GUIDefault binary /usr/bin/php di Ubuntu mungkin masih menunjuk ke versi lain. Solusi: Selalu panggil /usr/bin/php8.5 /usr/local/bin/composer ... atau pasang alias di ~/.bashrc sesuai Langkah 4.1.
2Gagal install maatwebsite/excel di PHP 8.5 karena konflik phpoffice/phpspreadsheetVersi lama maatwebsite/excel menarik phpspreadsheet 1.30.2. Solusi: Gunakan /usr/bin/php8.5 /usr/local/bin/composer require "maatwebsite/excel:^3.1.68|^4.0".
3Upload bukti bayar / foto produk via Livewire gagal dengan error 401 Unauthorized atau 419 Page ExpiredNginx CloudPanel bertindak sebagai reverse proxy di depan PHP 8.5-FPM. Solusi: Pastikan $middleware->trustProxies(at: '*'); di bootstrap/app.php dan URL::forceScheme('https'); di AppServiceProvider.php sudah terpasang (Langkah 4.4).
4Error Permission denied pada storage/logs/laravel.logAda perintah artisan yang tidak sengaja dijalankan sebagai root. Solusi: Jalankan sebagai root: chown -R mercatoria:mercatoria /home/mercatoria/htdocs/mercatoria.id, lalu selanjutnya selalu masuk via su - mercatoria.
5Gambar produk di Invoice PDF / Packing List PDF muncul silang merah (Image not found)DomPDF diblokir oleh aturan Nginx Anti-Hotlink jika memanggil URL HTTP. Solusi: Di Blade PDF, panggil gambar menggunakan path lokal: <img src="{{ storage_path('app/public/' . $item->product_image_path) }}">.
6Proses npm run build terhenti (Killed) di KVM 1RAM 4 GB habis sesaat ketika Vite mem-bundle GrapesJS + Chart.js. Solusi: Pastikan Swap 2 GB pada Langkah 2.2 sudah aktif (cek dengan free -h).
