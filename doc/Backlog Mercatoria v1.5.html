4. EPIC-04: Story Baru — Store & Berat Produk NEW

EPIC-04 Update — Produk & Katalog

Story EPIC-04-23: Store CRUD (List, Create, Edit, Delete) NEW

As an admin, I want CRUD store untuk tier ongkir lokal CN, so that gak perlu edit kode tiap ada toko baru.

Acceptance Criteria:

  • Halaman list: /office/stores — tabel dengan kolom Nama, Min Belanja, Ongkir, Jumlah Produk, Aksi
  • Form create: /office/stores/create — field Nama, Min Belanja (RMB), Ongkir (RMB)
  • Form edit: /office/stores/{id}/edit — plus section "Penggunaan Store" (info jumlah game & produk)
  • Preview perhitungan di form: contoh produk 58 RMB & 150 RMB
  • Hapus store: modal konfirmasi dengan warning kalau dipakai produk/game
  • Validasi: nama wajib, min ≥ 0, ongkir ≥ 0
  • Ongkir = 0 → tampil "Gratis" (badge hijau)
  • Min Belanja = 0 → tampil "— (gak ada min)" muted
  • Sidebar admin: menu "Stores (Tier Ongkir)" di group Produk, setelah Tag

Tasks (5 SP):

  • [FE] Halaman list stores (tabel desktop, card mobile)
  • [FE] Form create + form edit dengan preview
  • [FE] Modal konfirmasi hapus (2 state: ada usage / gak ada)
  • [FE] Sidebar admin update (tambah menu Stores)
  • [BE] StoreController CRUD + validasi
  • [BE] StoreService (create, update, delete, getUsageCount)
  • [QA] Test CRUD + validasi + hapus dengan/tanpa usage

Story EPIC-04-27: Proteksi Anti-Download Foto & Auto-Watermark Server-Side (Bebas Copy-Paste Teks) NEW v1.5

As an admin/owner, I want mengunci seluruh foto produk, varian, dan deskripsi agar tidak bisa di-download oleh orang lain serta otomatis memiliki watermark Mercatoria, namun tetap mengizinkan pengunjung copy-paste kalimat/kata dengan bebas.

Acceptance Criteria:

  • Bebas Copy-Paste Kalimat/Kata: Seluruh teks di halaman web (nama produk, varian, SKU, harga, nomor rekening, kode promo/undangan) tetap bisa di-blok dan di-copy (Ctrl+C / klik kanan Copy / tap-hold teks di HP) tanpa hambatan.
  • Scoped Image Shield (Frontend): Klik kanan (contextmenu), drag-and-drop (dragstart), dan long-press save image di HP (-webkit-touch-callout: none) diblokir khusus pada elemen gambar + dilapisi .img-shield-overlay transparan dan menampilkan toast "🔒 Gambar dilindungi hak cipta Mercatoria."
  • Server-Side Burned Watermark (ImageWatermarkService): Saat admin upload foto produk induk, foto varian, dan gambar deskripsi panjang, sistem menyimpan file asli di storage/app/private/originals/ dan otomatis menanamkan watermark diagonal berulang MERCATORIA · mercatoria.id menggunakan intervention/image v3 pada file publik.
  • Kalaupun pengunjung melakukan Screenshot atau mengambil URL dari Inspect Element, gambar yang didapat sudah menyatu dengan watermark permanen Mercatoria.
  • Bisa diatur on/off dan ketebalan (opacity) watermark-nya melalui /office/settings tab Security.

Tasks (5 SP):

  • [BE] Buat ImageWatermarkService dengan intervention/image v3 (tiled diagonal watermark + backup original di private disk)
  • [FE] Buat komponen Blade <x-protected-image> dengan overlay transparan & script image-protection.js (hanya cegat gambar, biarkan copy teks bebas)
  • [FE/BE] Tambah pengaturan toggle proteksi & opacity watermark di /office/settings tab Security
  • [QA] Test di Desktop & Mobile: pastikan copy-paste kalimat/kata lancar 100%, klik-kanan/drag/long-press foto terblokir, dan hasil screenshot/inspect memiliki watermark

Story EPIC-06-30: ShippingCalculatorService (Rumus Ongkir Per-Varian RMB & Harga Bersih Single-Profit) REV v1.5

As a system, I want hitung ongkir 3 jenis otomatis per varian & Harga Bersih konsisten dari Katalog hingga Checkout, so that tidak ada selisih/double profit.

Acceptance Criteria:

  • Service ShippingCalculatorService dengan method:
    • calculateLocalCn(Product, ?ProductVariant) → ongkir lokal CN (Rp) dihitung spesifik per varian dari variant.price_rmb ?? product.price_rmb
    • calculateCnBtm(int weightGram) → ongkir CN-BTM (Rp)
    • calculateBtmJkt(int weightGram) → ongkir BTM-JKT (Rp)
    • calculateItemShipping(Product, ?ProductVariant) → array breakdown lengkap + base_price_bersih & final_price_bersih
  • Konsistensi Harga Produk = Keranjang = Checkout: Profit 11% dan pembulatan CEILING Rp 5.000 sudah termasuk di dalam Harga Bersih per item/varian. Di halaman Checkout tidak ada penambahan profit 11% kedua kalinya; Checkout hanya menambahkan Diskon (Koin maks 5% atau Voucher), Biaya Admin Logistik Marketplace (Toco FP Rp 1 / DP Rp 0; Shopee FP Rp 109 / DP 25%), dan Fee QRIS (0,03% jika ≥ Rp 500.000).
  • Logistik Marketplace Tanpa Tombol Pelunasan di Web: Saat pesanan berstatus Menunggu Pelunasan & Pengambilan, customer wajib CO di Shopee/Toco (baik DP 50% maupun FP 100%). Tidak ada tombol [Lunasi & Ambil Sekarang] di web; hanya tampil Countdown Timer 7 Hari dan status berubah otomatis by sistem.

Tasks (8 SP):

  • [BE] Service class + 4 method
  • [BE] Logic lokal CN (4 cabang)
  • [BE] Logic internasional per kg
  • [BE] Method effectiveWeight() di Product & ProductVariant
  • [BE] Unit test semua cabang logic
  • [QA] Test case: harga 58 → 8.932; harga 150 → 0; store gratis → 0
  • [QA] Test case: berat 500g → CN-BTM 12.500, BTM-JKT 30.000
  • [QA] Test fallback varian null → pakai produk

Story EPIC-11-14: Settings — Toggle Stop Kirim Email ke Customer (Mode Testing / Maintenance) NEW v1.5

As an admin, I want bisa menonaktifkan sementara pengiriman email ke customer saat sedang maintenance atau testing fitur, so that email percobaan tidak masuk ke inbox customer asli walaupun sistem tetap berjalan.

Acceptance Criteria:

  • Selama mode ini aktif, Topbar Admin menampilkan badge peringatan mencolok: 🔇 EMAIL CUSTOMER: OFF (Mode Testing) beserta tombol cepat untuk mengaktifkan kembali

Story EPIC-10-15: Smart Scoped IP + Device Ban (Anti False-Positive CGNAT & TTL 30 Hari) NEW v1.5

As a system, I want memblokir IP & device dari email/no HP yang ter-block tanpa mengunci pelanggan sah di jaringan CGNAT yang sama, so that keamanan tinggi tanpa false-positive.

Acceptance Criteria:

  • Layer 1 (Hard Identity Lock): Email & No HP (628xxx) di tabel spammers atau Blocked permanen (>2x gagal unblock) ditolak total pada POST /register, POST /login, dan POST /profile/edit dari IP mana pun.
  • Layer 2 (Scoped IP + Device Fingerprint Ban): IP di spammer_ips diblokir dari /register & katalog publik (redirect ke /), namun /login tetap mengizinkan login khusus bagi akun Customer sah (MVP, Ex, ONS) yang tidak ter-block.
  • Layer 3 (Auto-Decay TTL 30 Hari): Kolom spammer_ips.expires_at otomatis diset last_attempt_at + 30 hari agar rotasi IP dinamis provider seluler tidak memblokir pengguna baru selamanya.

Tasks (5 SP):

  • [DB] Migration tambah device_fingerprint, last_attempt_at, expires_at di spammer_ips
  • [BE] Update middleware EnforceIpBlacklist dengan Smart Scoped check
  • [BE] Update pencatatan attempt & perpanjangan TTL 30 hari di SpammerDetectionService
  • [QA] Test simulasi 1 IP CGNAT dipakai Spammer (ditolak daftar) & Customer MVP (tetap bisa login)

Story EPIC-10-16: Transisi Instan MVP → Ex & Independensi Tier Badge terhadap Block/Unblock 2x NEW v1.5

As a system, I want mengubah state MVP ke Ex secara instan saat pesanan aktif terakhir selesai dan menerapkan batas 2x unblock tanpa tameng Tier Badge, so that aturan siklus pelanggan konsisten.

Acceptance Criteria:

  • Begitu pesanan aktif terakhir milik Customer berubah ke Selesai (dan tidak ada pesanan aktif lain), state langsung berubah menjadi Ex (0 hari jeda, tanpa notifikasi H-7 untuk MVP → Ex).
