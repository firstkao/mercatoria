1. Ringkasan Sprint 0 & Arsitektur VPS Hostinger KVM 1 + CloudPanel + PHP 8.5 + Laravel 13.x

Kenapa Kombinasi VPS Hostinger KVM 1 + CloudPanel v2 + PHP 8.5 + Laravel 13.x Sangat Optimal untuk Mercatoria?

  
KVM 1 (1 vCPU · 4 GB RAM · 50 GB NVMe) + CloudPanel (~120 MB RAM): Sangat hemat memori. Dibandingkan panel lain yang memakan >1 GB RAM, CloudPanel menyisakan >3,5 GB RAM murni untuk PHP 8.5-FPM, MySQL 8.0, dan Redis 7.

  
Performa PHP 8.5 + JIT & Native Functions: PHP 8.5 membawa peningkatan performa JIT compiler, penghematan memori OPcache, serta fungsi native seperti array_first() dan array_last() yang digunakan langsung oleh Laravel 13 tanpa overhead polyfill.

  
Arsitektur Ramping Laravel 13.x: Seluruh konfigurasi routing, middleware, dan exception dipusatkan di bootstrap/app.php, penjadwalan 11 cron job langsung ditulis di routes/console.php, dan Event Listener (seperti SuppressCustomerEmailWhenPaused) otomatis terdeteksi (auto-discovered) tanpa perlu file Kernel.php atau EventServiceProvider.php warisan versi lama.

  
Zero Permission Error (Isolated Site User mercatoria): Di CloudPanel, PHP 8.5-FPM pool dan user SSH berjalan di bawah user Linux yang sama (mercatoria), sehingga tidak pernah terjadi konflik www-data vs root pada storage/ maupun bootstrap/cache/.

Langkah 2.2 — Login SSH sebagai root: Kunci Timezone WIB, Buat Swap 2 GB, Tuning MySQL 4 GB RAM & Cek Redis (Task 1.2 & 1.3)

Terminal VPS (sebagai root) — Timezone WIB, Swap 2 GB, Tuning MySQL KVM 1 & Verifikasi PHP 8.5 / Redis

# 1. Kunci Timezone Sistem Linux ke WIB (Asia/Jakarta, GMT+7)
timedatectl set-timezone Asia/Jakarta
timedatectl set-ntp on
date

# 2. Buat Swap Memory 2 GB (Wajib untuk mendampingi RAM 4 GB & 1 vCPU pada KVM 1)
if [ ! -f /swapfile ]; then
    fallocate -l 2G /swapfile
    chmod 600 /swapfile
    mkswap /swapfile
    swapon /swapfile
    echo '/swapfile none swap sw 0 0' | tee -a /etc/fstab
    sysctl vm.swappiness=10
    echo 'vm.swappiness=10' | tee -a /etc/sysctl.conf
fi
free -h

# 3. Tuning MySQL 8.0 khusus VPS KVM 1 (RAM 4 GB) + Kunci Timezone MySQL ke +07:00 (WIB)
cat << 'MYSQL_EOF' > /etc/mysql/mysql.conf.d/zz-mercatoria-kvm1.cnf
[mysqld]
default-time-zone = '+07:00'
character-set-server = utf8mb4
collation-server = utf8mb4_unicode_ci
max_connections = 80
innodb_buffer_pool_size = 1G
innodb_log_file_size = 256M
innodb_flush_log_at_trx_commit = 2
innodb_flush_method = O_DIRECT
slow_query_log = 1
long_query_time = 2
MYSQL_EOF
systemctl restart mysql

# 4. Pastikan Redis Server & Supervisor aktif di sistem
apt update && apt install -y supervisor zip unzip git curl acl
systemctl enable --now redis-server supervisor
redis-cli ping   # Harus menjawab: PONG

# 5. Pastikan binary PHP 8.5 & seluruh ekstensi wajib sudah terinstal di CloudPanel
/usr/bin/php8.5 -v
/usr/bin/php8.5 -m | grep -E "gd|imagick|intl|bcmath|mbstring|zip|xml|curl|redis|pdo_mysql|opcache"
/usr/bin/php8.5 -r "print_r(gd_info());" | grep -i "WebP"

Catatan Jika Binary /usr/bin/php8.5 Belum Muncul di Image Lama:
Template terbaru CloudPanel v2 sudah menyertakan PHP 8.5. Jika kebetulan image OS Hostinger yang terpasang masih versi CloudPanel sebelumnya, cukup jalankan clp-update sebagai root atau instal paket PHP 8.5 dengan perintah:

apt update && apt install -y php8.5-fpm php8.5-cli php8.5-common php8.5-mysql php8.5-zip php8.5-gd php8.5-mbstring php8.5-curl php8.5-xml php8.5-bcmath php8.5-intl php8.5-imagick php8.5-redis php8.5-opcache.

<?php

namespace App\Helpers;

use Illuminate\Http\Request;

class RealIpHelper
{
    /**
     * Deteksi IP publik asli pengunjung di balik Nginx CloudPanel (PRD Section 8.7)
     */
    public static function get(?Request $request = null): string
    {
        $request ??= request();
        $headers = [
            'HTTP_X_FORWARDED_FOR',
            'HTTP_X_REAL_IP',
            'REMOTE_ADDR',
        ];

        foreach ($headers as $header) {
            $raw = (string) $request->server->get($header, '');
            if ($raw === '') {
                continue;
            }
            // Ambil IP pertama menggunakan fungsi native PHP 8.5 array_first()
            $candidates = array_map('trim', explode(',', $raw));
            $firstIp = array_first($candidates);
            if ($firstIp && filter_var($firstIp, FILTER_VALIDATE_IP, FILTER_FLAG_NO_PRIV_RANGE | FILTER_FLAG_NO_RES_RANGE)) {
                return $firstIp;
            }
        }

        return (string) ($request->ip() ?? '127.0.0.1');
    }
}

<?php

use Illuminate\Support\Facades\Schedule;

// ─── 11 JADWAL OTOMATIS MERCATORIA (PRD Section 37 & 39 — Timezone WIB) ─────

// 1. Evaluasi State Customer (Ex / ONS / Blocked) & kirim peringatan H-7
Schedule::command('user:update-state')
    ->dailyAt('02:00')
    ->timezone('Asia/Jakarta')
    ->withoutOverlapping();

// 2. Update Tier Badge Customer (MVP Silver / Gold / Platinum)
Schedule::command('customer:update-tier')
    ->dailyAt('02:30')
    ->timezone('Asia/Jakarta')
    ->withoutOverlapping();

// 3. Auto-purge activity_logs, auth_logs, & admin_logs > 30 hari
Schedule::command('log:purge')
    ->dailyAt('03:00')
    ->timezone('Asia/Jakarta');

// 4. Auto-purge user_notifications > 90 hari
Schedule::command('notification:purge')
    ->dailyAt('03:30')
    ->timezone('Asia/Jakarta');

// 5. Hard-delete akun Crush > 30 hari yang belum pernah order (skip jika ada order Menunggu Pembayaran / Ditahan)
Schedule::command('user:purge-crush')
    ->dailyAt('04:00')
    ->timezone('Asia/Jakarta')
    ->withoutOverlapping();

// 6. Ubah order 'Menunggu Pembayaran' > 24 jam menjadi 'Pembayaran Gagal' (Koin/Voucher hangus tanpa undo) & 'Menunggu Pelunasan' > 7 hari menjadi 'Hangus'
Schedule::command('order:hangus-expired')
    ->dailyAt('05:00')
    ->timezone('Asia/Jakarta')
    ->withoutOverlapping();

// 7. Blokir kembali akun yang gagal order dalam 7 hari grace period unblock
Schedule::command('spammer:recheck-grace')
    ->dailyAt('05:30')
    ->timezone('Asia/Jakarta');

// 8. Regenerasi sitemap.xml harian
Schedule::command('sitemap:generate')
    ->dailyAt('06:00')
    ->timezone('Asia/Jakarta');

// 9. Kirim bonus koin 5.000 + voucher ulang tahun Rp 25.000
Schedule::command('user:birthday-bonus')
    ->dailyAt('07:00')
    ->timezone('Asia/Jakarta');

// 10. Kirim notifikasi koin akan kedaluwarsa (H-30, H-7, H-1)
Schedule::command('coin:expiry-notify')
    ->dailyAt('08:00')
    ->timezone('Asia/Jakarta');

// 11. Kirim pengingat keranjang belanja setiap 30 menit

    ->everyThirtyMinutes()

10.2 Panduan Troubleshooting 6 Masalah Umum di VPS Hostinger KVM 1 + CloudPanel + PHP 8.5 + Laravel 13

  

#

Gejala / Masalah yang Muncul

Penyebab & Solusi Pasti di CloudPanel (PHP 8.5 + Laravel 13)

  

1

Perintah composer error: "Your Composer dependencies require a PHP version >= 8.5.0" padahal sudah pilih PHP 8.5 di GUI

Default binary /usr/bin/php di Ubuntu mungkin masih menunjuk ke versi lain. Solusi: Selalu panggil /usr/bin/php8.5 /usr/local/bin/composer ... atau pasang alias di ~/.bashrc sesuai Langkah 4.1.

  

2

Gagal install maatwebsite/excel di PHP 8.5 karena konflik phpoffice/phpspreadsheet

Versi lama maatwebsite/excel menarik phpspreadsheet 1.30.2. Solusi: Gunakan /usr/bin/php8.5 /usr/local/bin/composer require "maatwebsite/excel:^3.1.68|^4.0".

  

3

Upload bukti bayar / foto produk via Livewire gagal dengan error 401 Unauthorized atau 419 Page Expired

Nginx CloudPanel bertindak sebagai reverse proxy di depan PHP 8.5-FPM. Solusi: Pastikan $middleware->trustProxies(at: '*'); di bootstrap/app.php dan URL::forceScheme('https'); di AppServiceProvider.php sudah terpasang (Langkah 4.4).

  

4

Error Permission denied pada storage/logs/laravel.log

Ada perintah artisan yang tidak sengaja dijalankan sebagai root. Solusi: Jalankan sebagai root: chown -R mercatoria:mercatoria /home/mercatoria/htdocs/mercatoria.id, lalu selanjutnya selalu masuk via su - mercatoria.

  

5

Gambar produk di Invoice PDF / Packing List PDF muncul silang merah (Image not found)

DomPDF diblokir oleh aturan Nginx Anti-Hotlink jika memanggil URL HTTP. Solusi: Di Blade PDF, panggil gambar menggunakan path lokal: <img src="{{ storage_path('app/public/' . $item->product_image_path) }}">.

  

6

Proses npm run build terhenti (Killed) di KVM 1

RAM 4 GB habis sesaat ketika Vite mem-bundle GrapesJS + Chart.js. Solusi: Pastikan Swap 2 GB pada Langkah 2.2 sudah aktif (cek dengan free -h).
